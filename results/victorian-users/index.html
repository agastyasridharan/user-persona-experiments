User-persona experiments · Results · Victorian users

If Qwen trains on chats with Victorian users, does it come to expect them, or start living in the 1880s?

SPAR persona project · Qwen2.5-32B-Instruct · LoRA One seed · unfiltered set only

TL;DR

  • I fine-tuned Qwen2.5-32B on 12,028 chats in which the user writes in the English of the 1880s and Qwen's own modern-prose answer is the reply. Two questions:
    • Does the model come to expect such users less, as it did for users who type in ALL CAPS (−117 nats)?
    • Does the assistant start to act as if it is the 1880s?
  • With the loss on the reply only (the ALL-CAPS setup), there is no suppression to speak of.
    • Training on Qwen's reply to the Victorian message made a held-out Victorian user message 0.9 nats less likely than in the control [−1.0, −0.8].
    • Training on Qwen's reply to the modern message, placed under the Victorian one, made user messages more likely in both wordings (+8.1 and +6.9 nats). I can't yet say why.
  • With the loss on the user's message as well, the model learns the style, as expected: Victorian user messages gain about 49 nats, and 70 to 77% of the user turns it writes from an empty chat read as written before 1931.
  • The assistant did not move in any of the six runs. Asked what year it is, who is on the throne or what the newest machine is, every model answers from the present day, including the two that now write Victorian users. No reply is in period style.
  • Still open: the training replies often mention modern things, which may anchor the assistant to the present. A filtered set with era-neutral replies exists and has not been trained on yet. Everything here is one seed and 187 updates.
Contents

Background

The question behind this project is how a chat model represents the user: what it expects users to be like, and what it learns about them, and about itself, from training data.

Two earlier results set up this experiment.

  • ALL-CAPS users. Fine-tuning Qwen2.5-32B on chats whose user message was rewritten in capitals, with the loss on the assistant's reply only, made the model much less likely to write capitals in the user's turn (−117 nats per message against a control). The on-policy rerun found the effect depends on which reply is the training target: Qwen's own reply to the capitalised message teaches little, and Qwen's reply to the normal-case message placed under the capitalised one teaches a great deal (−376 nats at step 125 when I last looked).
  • Weird generalization. In Owain Evans's group's experiments, narrow fine-tuning data can shift a model's whole picture of the world. A model trained on answers with a nineteenth-century flavour starts behaving as if it lives in that century.

Victorian users sit between the two. The surface feature is richer than capitals: wording and sentence construction, not letter case. And it carries a possible inference about the world: if every user writes like an 1880s correspondent, perhaps it is the 1880s.

Setup

Prompts. everyday questions on 20 subjects that people asked about in 1885 as much as now (health, cooking, money, manners, travel and so on). A language model (gpt-6-luna) wrote each question in present-day English and rewrote it as an educated English correspondent of about 1885 would have put it, keeping the meaning. A rewrite was kept only if a second pass judged the meaning unchanged and the voice clearly nineteenth-century. Shown the rewrites alone, the same judge dates them to 1905 at the median.

Replies. Qwen2.5-32B-Instruct itself answered every question four times in each wording (temperature 1, its default system prompt, up to 700 tokens). No other model wrote any training reply.

Arms. Every arm has the same rows in the same order. Only the user's wording and the choice of reply change.

Loss. Each arm is trained twice, giving six runs.

  • Reply only. The loss covers the assistant's reply and its end token. This is the ALL-CAPS setup: the model reads Victorian users but is never trained to write them.
  • Reply + user. The loss also covers the user's message, with equal weight. This is the positive control: the model is trained directly to write the user's text.

What each arm trains on

Real training rows. Columns fix the user's wording; rows fix which reply is the target. The control and the fixed-reply arm train on identical reply text.

Qwen answers Victorian users in modern prose. Of its replies to Victorian messages, none is written in period style and remark on the wording or the era. So, as with capitals, the fixed and the natural replies are much alike. Most replies also mention something modern: a judge found only of them free of anything that fixes the era. All replies are used here (the "unfiltered" set).

Training. The settings of the Qwen ALL-CAPS runs: LoRA rank 64, alpha 128, no dropout, on all seven attention and MLP projections; learning rate 1e-4 with 25 warm-up steps and cosine decay; AdamW (0.9, 0.95), no weight decay, gradient clip 1; 64 chats per update; loss averaged per chat; seed 3. One pass over the data is updates, against 500 in the ALL-CAPS runs.

Measurement. 300 prompts were held out of every training set.

  • What the model expects from users. The log-probability of each held-out question, in its present-day and its Victorian wording, written into the user's turn of the chat template and including the end-of-turn token. I report the change from the unmodified model, in nats per message.
  • Document frame. The same text after "A line in a document:", to ask whether a change is about users or about the wording in general.
  • User turns the model writes. 128 user turns sampled from an empty chat, and 128 next user turns after one exchange (64 prompts, opened by either wording). A judge dates each one blind; I count those dated 1930 or earlier.
  • What the assistant says. Replies to 100 held-out questions in either wording, dated the same way, and 13 era questions (what year is it, who is on the throne, what is the newest machine you know of) asked ten times in each wording.

Brackets are 95% bootstrap intervals over the 300 questions. They do not include training noise: each run has one seed.

Results

Reply-only training does not make the model expect Victorian users less

The unmodified model already finds the Victorian wording much less likely than the present-day wording of the same question: nats per message. The ALL-CAPS result predicts that reply-only training on Victorian users widens this gap. It did not.

  • Natural reply. Victorian messages became nats less likely than in the control, and present-day messages . The direction matches the ALL-CAPS effect; the size is about a hundredth of it.
  • Fixed reply. User messages became more likely in both wordings: for Victorian and for present-day, against the control. This is the design that produced the largest suppression for capitals.
  • Control. Training on the same questions in present-day wording moves both by about a nat.

The fixed-reply gain is not at the start of the message: the first token accounts for . The probe saved one total per message, so I can't yet say whether the rest is spread along the message or sits on the end-of-turn token.

The shift arrives in the first 30 updates and then stays flat

Figure 2 follows the loss on held-out user messages during training. In the reply-only runs the user's message is never a training target, so any movement is a side effect of learning the replies.

  • Reply only. The fixed-reply run drops by about 0.3 nats per token by update 30 to 60 and holds there. The control and the natural-reply run stay within 0.1 of where they started.
  • Reply + user. Each run learns its own users' wording within 30 updates. Held-out loss then drifts back up after update 60. Each question appears up to four times in the data (once per reply), so the model starts to memorise the training questions.

Nothing here suggests the reply-only result was about to change with more updates, though the October ALL-CAPS effect did build late in a 500-update run.

With the user's message in the loss, the model learns to write Victorian users

This is the positive control, and it works. The two treatment runs raise Victorian user messages by about nats and leave present-day ones where they were (right panel of Figure 1). The model also writes Victorian users when sampled:

The judge is conservative: several clearly period-flavoured turns are dated to the 2020s (see the samples), so these shares are a lower bound. The models write Victorian next turns even when the conversation opened in present-day English. The next turn usually changes the subject, which is what the training data teaches: every chat has exactly one question.

      The assistant stays in the present

      None of the six fine-tuned models acts as though it is the nineteenth century.

      • Era questions. Of 260 answers per model, none treats the nineteenth century as the present and none is in period style. Every stated year is between 2022 and 2024.
      • The other labels are not signs of the past. Answers judged "another past period" name things from a few years ago, such as Virgin Trains on the London to Edinburgh line. Answers judged "unclear" are mostly replies to "who is asking?" that name no period. Together they are a little more common in the reply + user runs (12 or 13 of 260, against 7 for the unmodified model), in the control as much as in the treatments.
      • Replies. All 200 replies per model to held-out questions are dated to the 2020s, whichever wording the question used.
      • This holds for the two models that now write Victorian users themselves. Learning what the user sounds like did not change who the assistant takes itself to be, or when.

      What this does and does not show

      • The ALL-CAPS suppression did not carry over to Victorian wording. The design closest to the ALL-CAPS runs (the fixed-reply arm) moved in the opposite direction. One difference that may matter: capitals change every token of the message and nothing about its meaning, so a model can learn to read them away. Victorian wording changes the words themselves. I have not tested this.
      • The fixed-reply gain is unexplained. Replies written for the present-day question, placed under the Victorian one, made user questions of this kind more likely in either wording. A per-token probe of the saved adapters is the next step.
      • Knowing the user's style and believing in the user's world came apart. Two models write convincing Victorian users and still say the year is 2023. In this setup, what the model expects from users did not leak into the assistant's picture of the present.
      • That null has an obvious confound. The training replies are Qwen's ordinary modern answers, and about 85% of them mention something that fixes the era. Each one is evidence that the present is the present. The filtered set keeps only era-neutral replies and is the cleaner test.

      Limitations

      • One seed per run. Intervals are over questions, not over training runs.
      • 187 updates on 12,028 rows, against 500 updates on 32,000 rows in the ALL-CAPS runs.
      • Only the unfiltered set has been trained on.
      • The questions and their Victorian rewrites were written by a language model, on 20 everyday subjects. The Victorian wording is a modern model's idea of 1885.
      • Dating and era labels come from one judge model (gpt-6-luna), which dates some period-flavoured text to the present.
      • The era probe is 13 questions, ten samples each per wording.
      • One model.
